# Renda FII — versão inicial

Aplicativo web responsivo para registrar posições em FIIs e dividendos recebidos.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` em um navegador moderno (Chrome, Safari ou Edge).

## O que já faz
- Cadastro e remoção de FIIs, quantidade de cotas e preço médio.
- Registro de dividendos recebidos com data.
- Resumo do total investido, renda registrada no mês e dividendos no ano corrente.
- Exportação dos registros em arquivo JSON.
- Salvamento local no navegador, sem conta ou servidor.

Os dados ficam no navegador e não são sincronizados entre aparelhos. Não há cotação automática nem recomendação de investimento nesta primeira versão.
